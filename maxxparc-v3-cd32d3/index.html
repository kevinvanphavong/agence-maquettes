Pour le gérant du MaxxParc

  1. Réserver un anniversaire en ligne. L'âge de l'enfant filtre les 6 formules ; le parent choisit date et créneau selon vos horaires, et paie un acompte (taux en exemple, à caler avec vous). Les règles de votre page Anniversaire s'appliquent : au plus tard une semaine avant, Big Mercredi le mercredi après-midi hors vacances, LaserPizza le week-end matin.
  2. Une page légère. Pas de vidéo lancée automatiquement, photos compressées : le poids mesuré de cette page est affiché dans le haut de page.
  3. Faire revenir les familles. Une carte de fidélité dans le téléphone (points, bons) avec Vong Club. Le rappel pour l'anniversaire de l'année suivante est prévu, pas encore actif.
